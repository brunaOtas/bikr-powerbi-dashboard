## 📌 Sobre o projeto

Como estudante de Engenharia de Software, sei que uma boa análise de dados não depende apenas de gráficos bonitos, mas de uma base bem estruturada e de uma interface que facilite a tomada de decisão.

Este projeto simula o cenário de uma distribuidora do **setor de ciclismo** — bicicletas, peças e serviços — com o objetivo de transformar dados brutos de vendas em insights estratégicos para o negócio.

## 🧩 Etapas do desenvolvimento

| Etapa | Ferramenta | Descrição |
|---|---|---|
| 1. UI/UX | **Figma** | Layout, wireframe e identidade visual em *Dark Mode* para uma navegação limpa e moderna |
| 2. Arquitetura de dados | **Excel** | Organização e estruturação da base bruta com o histórico de vendas |
| 3. ETL | **Power Query** | Ingestão, limpeza, tratamento e modelagem dos dados brutos |
| 4. Data Storytelling | **Power BI + DAX** | Visuais interativos para faturamento temporal (ano/mês) e rankings de performance por funcionário e cargo comercial |

## 🎯 Aprendizados

Esse projeto foi um passo importante para consolidar minha prática em modelagem de dados, fórmulas DAX e design de interface focado na experiência do usuário (UX).
